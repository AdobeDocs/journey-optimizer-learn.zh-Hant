# Journey Optimizer中的CX Enterprise Coworker

同事是Adobe的對話式AI，與Adobe Journey Optimizer等CX Enterprise應用程式整合。 它會套用Adobe最佳實務，協助您有效率且準確地工作。 以簡單的語言描述您的工作。 您可以在註冊後透過電子郵件請求歡迎歷程，並在三天後進行跟進。 或者詢問，「從這個上傳的流程圖影像建立一個歷程」，然後同事會計畫工作。 它會在您連線的Adobe應用程式中執行任務，並顯示結果以供您檢閱。

對於Journey Optimizer而言，這表示花在設定歷程步驟、準備模擬和設定忠誠度挑戰上的時間更少，而花在檢閱和核准同事產生的內容上的時間則更多。 您在每個步驟都由您控制，而Co-worker處理計畫、執行和後續工作。

## 開始使用同事

同事的新手嗎？ 從這裡開始，全面瞭解如何協助您在Journey Optimizer和其他CX Enterprise應用程式中更有效率地工作。
