# 歷程畫布中的內容決策活動

瞭解 Journey Canvas 中的內容決定活動如何讓使用者運用 Adobe Journey Optimizer Decisioning 來提供個人化內容優惠方案。 使用此功能可根據擷取的優惠來路由輪廓，或將優惠傳送至外部系統，提升歷程的效能和個人化。
