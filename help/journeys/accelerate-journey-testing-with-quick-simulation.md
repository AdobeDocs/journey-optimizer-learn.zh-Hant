# 使用快速模擬加速歷程測試

快速模擬透過自動化關鍵流程，簡化客戶歷程測試。它會產生測試輪廓、協調事件、縮短等待時間，並驗證情境。此工具有助於在發佈前確保複雜歷程按預期運作，以節省時間並提高準確性。
