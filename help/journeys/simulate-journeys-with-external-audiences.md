# 使用外部客群模擬歷程

瞭解如何使用來自 CSV 檔案的外部客群輪廓或聯合客群構成 (包括設定檔中未儲存的屬性，例如票證 ID 或旅遊日期) 來模擬歷程。 此影片逐步解說如何篩選客群、使用外部屬性打造個人化訊息、建立模擬使用者，以及在歷程上線前模擬客群資料以驗證正確路徑。
